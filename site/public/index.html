Clips from a replay (optional)
  1. In the uploader press Clips from replays, and recording settings, pick a match and press Find highlights.
  2. Press Start recording, play that match's replay in Siege, and press F9 when each listed round's timer starts.

How it works

Siege saves a replay file for every round, but only for your last 10 to 12 matches. The uploader reads them on your PC, the server keeps the statistics, and the coach turns them into advice.

  1. Install the uploader on your PC

    Download the Windows app above. It finds your replay folder and watches it. Each new replay is read on your PC and only its few kilobytes of statistics are sent.

  2. Get your tokens

    A token is a password for this server. Take yours below. You need one for the PC and one for the phone.

  3. Install the Android app

    Open it, follow the three short steps, and enter the server address and your phone token.

  4. Play. Open the Coach.

    After each match, your replays arrive in a minute or two. The Coach scores the game against your own usual level and tells you what to try next.

Set up each device

  1. Open the uploader

    Unzip it and open R6ReplayUploader.exe.

  2. Fill in the form

    Server address and Upload token from the section above. For Replay folder, press Find. It is the folder named MatchReplay inside the game's install folder, which holds one folder per match.

  3. Press Save and start

    It uploads every replay the server does not have yet, then watches for new ones. A progress bar and a log show each upload with its speed.

  4. Leave it running

    Closing the window keeps it in the tray. Tick Start with Windows to never think about it again.

  1. Install and open the app

Help

Do I need an account or an API key?

No. The coach works only from your own replay files. There is an optional extra in the app for lifetime stats, but nothing depends on it.

Where are my replay files?

In a folder called MatchReplay inside Siege's install folder, for example …\Tom Clancy's Rainbow Six Siege\MatchReplay. It is created after your first recorded match. The game only keeps the last 10 to 12 matches, so keep the uploader running.

What happens to my replays?

The uploader reads each replay on your PC and sends only the small statistics (players in the match, kills, deaths, timings, results). The replay file itself stays on your PC. The one exception: if a replay cannot be read, for example after a game update, the file is sent whole (up to 20 MB) so it can be fixed; there is a checkbox in the uploader to turn that off. Statistics are available to anyone holding a phone token for this server, so do not treat it as private storage.

The Windows app says nothing was uploaded

Open the log (the Open log file button). It lists every file it looked at and why one was skipped. Check that the replay folder is the one that holds the match folders, and that the server address and token match.

Some of my rounds failed to analyse

New operators sometimes appear in the game before the replay reader knows them. Those rounds are marked failed and are read again after you update the uploader. If the uploader says Please update your uploader, download the newest version above.

The phone says it cannot reach the server

Check the address starts with https:// and has no spaces, and that you used the phone token, not the upload token.
